Superrocket: efficient kernel-based transformation selection for fast and accurate time series classification

期刊：The VLDB Journal · DOI：10.1007/s00778-026-01008-z · 语言：en · 摘要来源：已核验来源

Despite decades of progress in developing advanced time series classification (TSC) approaches, it remains a challenging problem to achieve fast and accurate TSC simultaneously. Recently, the kernel-based TSC solution has emerged as a rising paradigm due to its remarkable training efficiency and fairly high accuracy. However, existing kernel-based methods use abundant (e.g., 50 K) randomly generated transformations directly for feature extraction, ignoring that a portion of them can produce redundant or irrelevant features, causing unnecessary computational costs and bottlenecking their accuracy. Based on our observations, it is feasible to generate many more transformations (e.g., 400 K) using well-established kernel-based methods and select a subset that can produce high-quality features, so as to improve the TSC accuracy with little computational overhead to maintain the superior efficiency. Unfortunately, it is difficult for existing solutions to address the transformation selection problem for such a large number of candidates due to their high complexity and insufficient consideration of the correlation between transformations and classifiers. To tackle this issue, we propose SuperRocket, a novel approach that can efficiently select high-quality kernel-based transformations to achieve fast and accurate TSC. We customize a learnable indicating vector with two constraints to select all transformations simultaneously without iteratively building or evaluating the classifier as the existing solutions. On this basis, we model transformation selection as an unconstrained bi-level optimization problem of learning the optimal indicating vector that is regularized based on the constraints, and propose an end-to-end optimization algorithm to efficiently solve it. Theoretical analysis validates the effectiveness of SuperRocket. Extensive experiments on a total of 135 datasets show that our proposal not only outperforms existing selection solutions in terms of both accuracy and efficiency, but also achieves competitive accuracy and two orders of magnitude faster training speed compared to the state-of-the-art TSC method.

IQRE enables a cloud-native OLAP engine to dynamically adjust a query’s Degree of Parallelism (DOP) during execution. Index structures are fundamental for efficient query processing on large-scale datasets. Learned indexes model the indexing process as a prediction problem to overcome the inherent trade-offs of traditional indexes. However, most existing learned indexes optimize only for limited objectives like query latency or space usage, neglecting other practical evaluation dimensions such as update efficiency and stability. Moreover, many learned indexes rely on assumptions about data distributions or workloads, lacking theoretical guarantees when facing unknown or evolving scenarios, which limits their generality in real-world systems. In this paper, we propose LMG, a robust and efficient learned index framework designed to balance multiple performance dimensions. LMG integrates a decoupled routing structure with theoretical O(1) complexity for fixed key types and an optimal error threshold training algorithm that approaches O(1) overhead in practice. Furthermore, the framework enhances query performance by optimizing gapped data layout. Extensive evaluations show that our framework achieves competitive or leading performance across all key evaluation dimensions, including bulk loading (up to 7.55× faster), point queries (up to 1.68× faster), range queries (up to 11.41× faster), and mixed read-write throughput (up to 3.50× faster). Furthermore, LMG ensures robust long-term stability and high space efficiency (up to 6.26× smaller footprint). These results demonstrate that LMG significantly mitigates the trade-offs across multiple performance dimensions often observed in state-of-the-art approaches, offering a balanced and efficient framework.

Efficient shortest path counting in dynamic road network

The shortest path counting is an important problem for various applications in road networks, such as traffic analysis, reliability assessment, and navigation services. Existing methods, such as 2-hop labeling schemes, precompute shortest-path distances and counts to enable fast query responses, but they face scalability challenges in large and dynamically changing networks. In this work, we propose an efficient solution, Dynamic Count Labeling (DCL), for shortest path count queries on dynamic road networks. DCL consists of three key components: a tree hierarchy, a 2-hop count labeling scheme, and a shortcut count graph scheme. The tree hierarchy organizes the network to guide the 2-hop labeling design and ensures efficient query processing by limiting the search space to a small subset of relevant label entries. The shortcut count graph scheme enables efficient construction and dynamic maintenance of the 2-hop labels under edge weight increases and decreases. We further develop dynamic algorithms to update both the shortcut count graph and the 2-hop labels in response to network changes. Additionally, we introduce a parallel version of our algorithms that leverages the label structure for high parallel efficiency. Experimental results demonstrate that DCL can compete with existing approaches for static graphs in terms of construction time, index size and query time, while enabling efficient index updates for dynamic graphs, at a fraction of reconstruction costs.

Fast construction of partitioned learned Bloom filter with theoretical guarantees

期刊：The VLDB Journal · DOI：10.1007/s00778-026-01011-4 · 语言：en · 摘要来源：已核验来源

Bloom filter is a widely used classic data structure for approximate membership queries. Learned Bloom filters improve memory efficiency by leveraging machine learning, with the partitioned learned Bloom filter (PLBF) being among the most memory-efficient variants. However, PLBF suffers from high construction cost, with time complexity O(N³k), where N and k are hyperparameters. In this paper, we propose three methods, fast PLBF, fast PLBF++, and fast PLBF#, that reduce the construction complexity to O(N²k), O(Nklog⁡N), and O(Nklog⁡k), respectively. Fast PLBF preserves the original PLBF structure and memory efficiency. Although fast PLBF++ and fast PLBF# may have different structures, we theoretically prove they are equivalent to PLBF under ideal data distribution. Furthermore, for non-ideal scenarios, we introduce an instance-specific measure of deviation from the ideal distribution and use it to bound the resulting difference in memory efficiency between PLBF and fast PLBF++. Experiments on real-world datasets demonstrate that, under the default setting (N=1000 and k=5), fast PLBF, fast PLBF++, and fast PLBF# are up to 58.7, 74.5, and 75.7 times faster to construct than original PLBF, respectively. In an ablation with larger k, which enables the construction of more accurate PLBFs, the speedups reach 235, 865, and 871 times at k=50. Additionally, fast PLBF maintains the same data structure as PLBF, and fast PLBF++ and fast PLBF# achieve nearly identical memory efficiency.

Parajoin: A Parallelism-aware approximate filtered similarity join method in vector databases

期刊：The VLDB Journal · DOI：10.1007/s00778-026-01012-3 · 语言：en · 摘要来源：已核验来源

Vector databases are essential for large-scale multi-modal data management. Approximate similarity join, which aims to retrieve vector pairs satisfying a user-defined rule, is a fundamental operator in modern vector databases. As vectors are often associated with structured attributes, we define approximate range-filtered similarity join (ARFSJ): only vectors that additionally satisfy an attribute filter are considered. Existing solutions approach ARFSJ from two angles: (i) search-based methods that treat each vector as an independent approximate similarity search, and (ii) join-based methods that process the vectors in a locality-aware order. Both families repeatedly compute the search space, leading to redundant computation, and they overlook batch optimization, resulting in an imbalance between locality and parallelism in concurrent settings. We present ParaJoin, the first framework purposely designed for ARFSJ. ParaJoin introduces an adaptive partitioning algorithm that dynamically reconstructs partitions for arbitrary join ranges, and it develops batch optimization strategies that combine fine-grained task division with neighborhood result reuse. Extensive experiments on five real-world datasets demonstrate that, while maintaining high recall, ParaJoin achieves speedups of up to 17.3× and 218.6× over the state-of-the-art baselines for two representative types of ARFSJ, respectively.

Learned query optimizers (LQOs) can improve performance over time by incorporating feedback; however, they suffer from cold-start issues and often require retraining when workloads shift or schemas change. In such scenarios, LiDAR sensors continuously generate PC frames at a stable frequency. As consecutive frames often capture overlapping regions, they exhibit spatio-temporal redundancy, resulting in duplicated 3D points in both the relative coordinate system (centered on the sensor) and the absolute coordinate system (aligned with global positioning). To address this issue, we propose DUSTER, a deduplication framework for efficient point cloud storage and retrieval. Less is more: re-architecting the reachability query processing pipeline

期刊：The VLDB Journal · DOI：10.1007/s00778-026-01017-y · 语言：en · 摘要来源：已核验来源

Reachability query processing–determining if a path exists from one vertex to another in a large directed graph–is a fundamental operation underpinning many graph analytics. State-of-the-art systems universally employ multi-stage pipelines to accelerate these queries; however, they typically prioritize algorithmic complexity (e.g., minimizing comparison counts) while overlooking a critical architectural mismatch: for latency-sensitive queries, the bottleneck has shifted from computational complexity to memory access latency. We observe that even minor architectural adaptations to existing algorithms, such as adding or reordering stages, can yield significant performance gains, underscoring the necessity of system-level optimization. Worse still, detailed profiling exposes a “performance hard ceiling”: the topological-order filter, despite its negligible per query computational cost, incurs cumulative memory access latencies that consume over 50% of the total query time. This single bottleneck mathematically limits potential speedups to ≤2×, regardless of any downstream optimization. To break this ceiling, we propose a set of cache-centric design principles that prioritize cache efficiency and instruction-level parallelism. Guided by these principles, we present CacheReach, a re-architected pipeline that aligns query processing with modern hardware characteristics by jointly optimizing stage ordering, parallelism primitives, and data layout. CacheReachsystematically front-loads a cache-efficient “Stage 0” pre-filter–enabled by our novel CR-vectors–to resolve the vast majority of negative queries via single-cycle bitwise logic. This architectural decision effectively shields downstream stages from expensive memory accesses, shifting the critical path from memory-bound to compute-bound. Evaluated across diverse real-world datasets, CacheReachachieves end-to-end query time speedups of 3.17–10.82× over state-of-the-art frameworks. Our results validate that in the era of the memory wall, rethinking hardware-conscious pipeline architecture is as vital as the algorithm design itself.
