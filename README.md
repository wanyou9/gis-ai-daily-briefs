# GIS-AI Daily Briefs

这是“GIS-AI 期刊每日轮检简报”的公开移动端站点。

- 公开网址：<https://wanyou9.github.io/gis-ai-daily-briefs/>
- 主格式：响应式 HTML
- 时区：`America/Los_Angeles`
- 计划：每天凌晨 02:00；1-30 日按组轮检，所有真实第 31 日执行全刊更新审计
- 摘要图：仅期刊级汇总，最多点名 12 种有更新或异常期刊，不公开逐篇信息
- 首份 HTML 日报：2026-08-01
- 历史档案：2026 年 7 月已生成的 9 份 Word 简报已一次性转换为公开 HTML 阅读版，并保留 SHA-256 完整性校验；Word 原件只在内部审计目录保存

仓库只保存可公开的网页、摘要图、分级索引与部署配置，不保存 Word 原件、内部工作簿、状态 JSON、扫描凭据、自动化提示词或本地路径。
