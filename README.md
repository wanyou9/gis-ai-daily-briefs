# GIS-AI Daily Briefs

这是“GIS-AI 期刊每日轮检简报”的公开移动端站点。

- 公开网址：<https://wanyou9.github.io/gis-ai-daily-briefs/>
- 主格式：响应式 HTML
- 时区：`America/Los_Angeles`
- 计划：每天凌晨 02:00；1-30 日按组轮检，所有真实第 31 日执行全刊更新审计
- 摘要图：仅期刊级汇总，最多点名 12 种有更新或异常期刊，不公开逐篇信息
- 首份 HTML 日报：2026-08-01
- 历史档案：2026 年 7 月已生成的 9 份 Word 简报已一次性转换为公开 HTML 阅读版，并保留 SHA-256 完整性校验；Word 原件只在内部审计目录保存

仓库只保存可公开的网页、摘要图、分级索引与部署配置，不保存 Word 原件、内部工作簿、状态 JSON、扫描凭据、自动化提示词或本地路径。

## 发布前校验

月度 JSON 分片是公开索引的事实来源；根清单保留最近 31 份简报，首页按日期倒序展示，年度页列出全部已有月份。

外部发布器更新月度分片、年度清单和 `brief_index.json` 后，在提交前执行：

```sh
python scripts/render_navigation.py
python -m unittest discover -s tests -v
python scripts/validate_site.py
```

脚本只使用 Python 标准库（Python 3.10+）。导航生成器保留现有首页及年度页的样式和页头，只刷新正文；新年度需要先准备该年度页面模板。

校验覆盖任务对象、任务/日期反向索引、根清单与分片一致性、简报数量、文件存在性、月度入口、首页最新简报和年度月份入口。7 月历史迁移简报没有任务对象，日期索引直接引用历史简报编号；补做任务的计划日期可以早于简报日期。校验保留这两种已存在的格式。

GitHub Actions 在拉取请求和 `main` 发布时运行同一套测试和校验；校验失败会阻止 Pages 上传和部署，拉取请求本身不会部署。此仓库没有上游日报生成器，因此还需由外部发布器采用上述提交前命令；不要用导航生成器修补或猜测任务元数据。已有日报正文、不可变发布副本和摘要图不由这些脚本修改。
